Fórmulas y supuestos

Supuestos visibles

  • Capacidad = ⌊ventana neta (min) × 60 / tiempo de ciclo (s)⌋.
  • Volumen realizable = mínimo entre capacidad y 350 unidades disponibles.
  • Coste equivalente: A = €180/20 = €9 por turno; B = €950/20 = €47.50 por turno; referencia = €0 incremental.
  • Productividad mostrada = volumen realizable / horas de ventana neta.
  • Para el piloto B se usa el supuesto explícito de ajuste uno a uno: ciclo B = 72 + (C normal ingresado − 30) segundos. Debe validarse contra el anexo patrón.
  • Es un cálculo de régimen: no simula variabilidad, paros, secuencias ni dependencia entre observaciones.
