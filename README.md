# Caso 1 — Luciérnaga

Proyecto de Estudio y Diseño del Trabajo.

## Contenido
- `app/index.html`: aplicación web para evaluar capacidad, demanda, inventario y productividad. Descarga el archivo y ábrelo en un navegador moderno.
- `documentos/punto-control.md`: cálculos manuales, fórmulas, supuestos y discrepancias por validar.
- `documentos/extracto-datos-libro-original.json`: extracto estructurado de los datos y diagramas registrados en el Excel compartido.

## Uso
Abre `app/index.html` localmente en tu navegador. Modifica demanda, ventana neta, alternativa y, cuando corresponda, el tiempo normal C del piloto B.

## Nota sobre el archivo Excel
El conector de GitHub utilizado en esta sesión permite crear archivos de texto, pero no adjuntar directamente el binario XLSX. Por ello se agregó un extracto estructurado del libro. El Excel original debe cargarse manualmente en `documentos/` desde GitHub para conservarlo íntegro.
