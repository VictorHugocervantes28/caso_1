# Caso 1 — Luciérnaga

Proyecto de Estudio y Diseño del Trabajo. Incluye el libro de trabajo original, el punto de control de cálculos y una aplicación web para evaluar capacidad, cumplimiento de demanda, inventario y productividad.

Consulta `app/index.html` para abrir la herramienta en el navegador y `documentos/punto-control.md` para revisar los datos, fórmulas y supuestos.
